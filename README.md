# Employee Review Tracker

Веб-приложение для хранения и просмотра результатов периодической оценки сотрудников.

## Запуск

1. Убедитесь, что установлены Docker и Docker Compose.
2. Клонируйте репозиторий и перейдите в папку проекта.
3. Выполните: docker-compose up --build
4. Откройте в браузере http://localhost:8080

## Тестовые пользователи

- Анна Администратор (admin)
- Борис Менеджер (manager)
- Виктория Сотрудник (employee)

## Использование

1. Выберите пользователя на странице `/users`.
2. В зависимости от роли будут доступны различные функции:
- **Admin** – создание/редактирование/удаление периодов, полный доступ к отзывам.
- **Manager** – создание/редактирование/публикация отзывов, просмотр своих отзывов.
- **Employee** – просмотр только своих опубликованных отзывов.

## API

Коллекция Postman находится в файле `postman_collection.json`.

## Тестирование

Запуск unit-тестов: docker-compose run --rm test

## Структура проекта

- `main.go` – backend на Go.
- `static/` – статические файлы (CSS, JS).
- `templates/` – HTML-шаблоны.
- `migrations/` – миграции базы данных.
- `docker-compose.yml` – оркестрация контейнеров.
- `Dockerfile` – сборка приложения.
