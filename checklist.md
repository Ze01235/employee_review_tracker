# Чек-лист ручного тестирования Employee Review Tracker

## Сценарий 1: Создание и публикация отзыва (роль manager)

- [ ] Войти как Борис Менеджер (id=2)
- [ ] Перейти на страницу «Все оценки» (http://localhost:8080/reviews)
- [ ] Нажать кнопку «Создать отзыв»
- [ ] Заполнить форму:
  - Сотрудник: Виктория Сотрудник (id=3)
  - Рецензент: Борис Менеджер (id=2) – должен быть предустановлен
  - Период: Q1 2025 (или любой существующий)
  - Soft skills: 4
  - Hard skills: 5
  - Комментарий: «Хорошая работа»
- [ ] Нажать «Сохранить»
- [ ] Проверить, что произошёл редирект на страницу просмотра отзыва
- [ ] Нажать «Опубликовать»
- [ ] Подтвердить публикацию
- [ ] Убедиться, что кнопки «Редактировать» и «Опубликовать» исчезли, статус изменился на «published»
- [ ] Выйти (сменить пользователя) и войти как Виктория Сотрудник (id=3)
- [ ] Перейти на страницу «Мои оценки»
- [ ] Убедиться, что опубликованный отзыв виден, можно открыть его
- [ ] Попробовать открыть чужой отзыв по прямому URL – должна быть ошибка 403

## Сценарий 2: Редактирование отзыва (роль admin)

- [ ] Войти как Анна Администратор (id=1)
- [ ] Перейти на страницу «Все оценки»
- [ ] Найти отзыв со статусом draft (можно создать новый)
- [ ] Нажать «Просмотр» → «Редактировать»
- [ ] Изменить оценки и комментарий
- [ ] Сохранить
- [ ] Убедиться, что изменения применились
- [ ] Опубликовать отзыв
- [ ] Попробовать редактировать опубликованный отзыв – должно быть запрещено

## Сценарий 3: Управление периодами (только admin)

- [ ] Войти как Анна Администратор (id=1)
- [ ] Перейти в раздел «Управление периодами» (ссылка в шапке)
- [ ] Нажать «Создать период»
- [ ] Заполнить название, даты (конец >= начало)
- [ ] Сохранить – период появится в списке
- [ ] Нажать «Редактировать» у любого периода, изменить даты
- [ ] Сохранить – изменения применяются
- [ ] Нажать «Удалить» – подтвердить удаление
- [ ] Убедиться, что период исчез из списка

## Сценарий 4: Фильтрация отзывов

- [ ] Войти как admin
- [ ] На странице «Все оценки» выбрать период в фильтре, нажать «Применить»
- [ ] Убедиться, что отображаются только отзывы за выбранный период
- [ ] Выбрать сотрудника в фильтре
- [ ] Убедиться, что отображаются только отзывы выбранного сотрудника
- [ ] Сбросить фильтры через выбор пустых значений

## Сценарий 5: Доступ employee

- [ ] Войти как employee
- [ ] В шапке видна только ссылка «Мои оценки» (нет «Управление периодами»)
- [ ] На странице «Все оценки» не должно быть кнопки «Создать отзыв»
- [ ] В списке отзывов должны быть только опубликованные, где текущий пользователь – сотрудник
- [ ] На странице детального просмотра чужого отзыва (прямой URL) – ошибка 403

## Сценарий 6: Валидация формы

- [ ] Попробовать создать отзыв с оценкой 0 или 6 – ошибка
- [ ] Попробовать создать отзыв без комментария – ошибка
- [ ] Попробовать создать период с end_date < start_date – ошибка

## Сценарий 7: Производительность и доступность

- [ ] Проверить, что сайт адаптивен на мобильном устройстве (или в инструментах разработчика)
- [ ] Убедиться, что все состояния (loading, error, empty) отображаются корректно
